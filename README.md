# 하루_Haru「빈티지 스토리 모드 소개 3편 - 설정 파일 공유」

Vintage Story 모드 소개 3편 영상에서 사용한 커스텀 설정 파일(Config)을 공유합니다.

모드의 기본 설정을 직접 플레이하며 조정하여, 개인적으로 보다 적당하다고 느낀 난이도와 플레이 환경에 맞춰 제작한 설정입니다.

모드의 기본 설정이 너무 어렵거나, 영상에서 사용한 것과 같은 설정으로 플레이해보고 싶은 분들은 필요한 설정 파일을 내려받아 사용해보세요.

> **빈티지 스토리 버전 :** 1.22.3

> **주의 :** 모드 자체는 포함되어 있지 않습니다. 해당 모드를 먼저 설치한 후 설정 파일을 적용해주세요.

## 🛠️ 설치 방법

1. 먼저 게임에 아래 모드들을 설치합니다.

   - Rust Creatures Reworked
   - Rust Creatures Can Destroy Obstacles
   - Weather The Storm Shelter

2. 게임을 실행하여 월드에 접속한 후 종료합니다.

3. 깃허브 페이지 상단의 초록색 **Code → Download ZIP**을 눌러 `ModConfig-Files.zip`을 다운로드한 뒤 압축을 해제합니다.

4. 키보드에서 `Win + R`을 눌러 실행 창을 열고, 아래 경로를 입력합니다.

   `%appdata%\VintagestoryData`

5. `ModConfig` 폴더를 열고 압축 해제했던 ModConfig-Files 폴더에 들어 있는 설정 파일들(.json)을 넣습니다.

   > `ModConfig` 폴더가 없다면 `VintagestoryData` 폴더 안에 직접 `ModConfig` 폴더를 만들어 주세요.
   >
   > 기존에 같은 모드의 설정 파일이 있다면 백업한 후 덮어쓰는 것을 권장합니다.

6. 게임을 다시 실행하여 설정이 정상적으로 적용되었는지 확인합니다.

## 📁 포함된 설정 파일

### 1. Rust Creatures Reworked & Rust Creatures Can Destroy Obstacles

기본 설정에서는 몬스터의 **어그로 거리와 이동 속도, 블록 파괴 속도 등이 개인적으로는 너무 과하게 설정**되어 있다고 
느껴졌습니다.

직접 플레이하면서 여러 설정을 하나씩 조절해보고, 나름대로 적당하다고 느낀 밸런스로 설정했습니다.

기본 설정의 난이도가 너무 높게 느껴졌던 분들은 필요에 따라 사용해보세요.

---

### 2. Weather the Storm – Shelter

시한의 폭풍이 시작되면 플레이어 주변에서도 몬스터가 생성될 수 있기 때문에, 안전한 집이나 방어 시설을 만들어 놓더라도 바로 근처에서 몬스터가 나타나는 경우가 있습니다.

해서 이를 방지하기 위해 본 모드를 사용했습니다.

이 설정에서는 기본값인 **6블록보다 범위를 넓혀 플레이어 중심 12블록, 지름 약 24블록**의 공간을 보호 구역으로 설정했습니다.

이를 통해 보호 구역 안에 방어 타워나 방어 거점을 만들고, 바깥에서 몰려오는 몬스터들을 상대하는 방식으로 플레이할 수 있도록 조정했습니다.

또한 조건을 만족하는 실내에서는 몬스터가 생성되지 않도록 설정하여, 제대로 된 방어 시설과 안전한 거점을 구축하는 것도 가능합니다.

## ⚠️ 참고사항

* 이 저장소에는 **모드 자체가 포함되어 있지 않습니다.**
* 각 모드가 설치되어 있어야 설정 파일이 정상적으로 적용됩니다.
* 설정 파일은 **Vintage Story 1.22.3** 환경에서 사용한 것입니다.
* 모드 버전이 달라질 경우 설정 항목이 변경되거나 정상적으로 적용되지 않을 수 있습니다.
* 개인적인 플레이 스타일을 기준으로 조정한 설정이므로 원하는 난이도에 맞게 자유롭게 수정해서 사용하셔도 됩니다.
